# Diabetes Health Analysis
## Project Overview
This project was completed as part of the Data Science program at LaGuardia Community College. It involved using Python to explore a diabetes-related healthcare dataset and examine prescription data across gender, race, and age ranges. Through this project, I developed my understanding of data manipulation, grouping, and visualization while learning how to use Python to identify patterns in data.

## Objectives
* Explore healthcare data using Python.
* Compare prescription data across gender, race, and age ranges.
* Practice grouping, sorting, and summarizing data with Pandas.
* Create visualizations to compare demographic categories.
* Develop practical data analysis skills using a real-world dataset.
  
## Tools & Technologies
* **Python** - data analysis and manipulation
* **Pandas** - data preparation, grouping, and aggregation
* **NumPy** - numerical operations
* **Matplotlib** - data visualization
* **Jupyter Notebook** - interactive analysis and documentation
  
## Methodology
1. Column Preparation: Renamed the dataset columns to improve readability, including race to Race, gender to Gender, age to Age, and num_medications to Number of Rx.
2. Demographic Analysis: Examined medication counts across gender, race, and age categories.
3. Data Aggregation: Used Pandas grouping and counting operations to summarize dataset entries by demographic category.
4. Data Visualization: Created bar charts to compare the distribution of entries across racial categories.
5. Data Quality Review: Identified unspecified race values represented by ? and considered their importance when interpreting the analysis.

## Key Findings
* **Race comparison**: The Caucasian category had 76,099 non-null entries in the Number of Rx column, followed by African American at 19,210.
* **Unspecified race**: The dataset contained 2,273 entries labeled ?.
* **Demographic scope**: The analysis examined gender, race, and age ranges to explore medication-related patterns within the dataset.

The reported counts represent dataset entries, not necessarily unique patients or individual prescriptions. The findings describe the analyzed data and should not be interpreted as evidence of differences in medication effectiveness or healthcare outcomes.
