# Regents Examination Report Analysis
## Project Overview
This project was completed as part of the Data Science program at LaGuardia Community College. It uses Python-based data analytics techniques to explore Regents examination report data and investigate patterns within the available educational dataset.

## Objectives
Prepare and organize the dataset for analysis.
Examine examination-related variables and reported results.
Explore trends and differences within the data.
Use Python to summarize and interpret findings.
