# NYPD Arrest Data Analysis
## Project Overview
This project was completed as part of the Data Science program at LaGuardia Community College. It applies Python-based data analytics techniques to NYPD arrest data, providing hands-on experience preparing, exploring, and interpreting a real-world public dataset.

## Objectives
Prepare arrest data for analysis.
Manipulate and examine relevant dataset variables.
Explore patterns and trends within the available records.
Apply Python data analysis libraries to investigate the dataset.
## Tools & Technologies
Python
Pandas
NumPy
Jupyter Notebook
## Methodology
The analysis uses a Jupyter Notebook to work with NYPD arrest data. The data-cleaning procedures, variables examined, and analytical methods will be documented based on the code and results in the notebook.

## Key Findings
To be completed using the actual results of the analysis. Findings should describe what the data shows without making unsupported conclusions about individuals or groups.
