# Data Analysis Projects | Python Fall 2023 Course
## Data Analytics Portfolio | LaGuardia Community College
## Overview
This repository showcases my work and projects completed as part of the Data Science program at LaGuardia Community College. Throughout the program, I developed hands-on experience working with datasets, cleaning and transforming data, performing exploratory data analysis, and extracting meaningful insights using Python and its data analysis libraries.

Using tools such as Python, Pandas, and NumPy, I learned to prepare datasets for analysis, identify patterns and trends, and turn raw data into meaningful information. The program emphasized practical, project-based learning and applying analytical techniques to real-world datasets.

## Technical Skills
Programming: Python
Data Manipulation: Pandas, NumPy
Data Cleaning: Handling missing values, identifying inconsistencies, and preparing datasets for analysis
Exploratory Data Analysis (EDA): Examining datasets, identifying patterns, and interpreting trends
Data Visualization: Creating charts and visual summaries using Matplotlib and Seaborn
