
# Data Analysis Projects | Python Fall 2023 course
Data Analytics Portfolio | LaGuardia Community College
## Overview
This repository showcases my work and projects completed as part of the Data Science program at LaGuardia Community College. Throughout the program, I developed hands-on experience working with large datasets, cleaning and transforming raw data, performing exploratory data analysis, and extracting meaningful insights using Python and its data analysis libraries.

Using tools such as Python, Pandas, and NumPy, I learned to prepare datasets for analysis, identify patterns and trends, and turn raw data into meaningful information. The program emphasized practical, project-based learning and applying analytical techniques to real-world datasets.

## Technical Skills
Programming: Python
Data Manipulation: Pandas, NumPy
Data Cleaning: Handling missing values, correcting inconsistencies, and preparing datasets for analysis
Exploratory Data Analysis (EDA): Examining datasets, identifying patterns, and interpreting trends
Data Analysis: Using Python to investigate datasets and communicate findings

## Capstone Project: NYPD Arrest Data Analysis
As a culminating project, I analyzed NYPD arrest data using Python in a Jupyter Notebook. This project provided an opportunity to apply the data-cleaning, manipulation, and analytical techniques developed throughout the program to a real-world dataset.
