NYC Parking Violations Analysis
Project Overview
This capstone project was completed as part of the Data Science program at LaGuardia Community College. The project applies Python-based data analytics techniques to New York City parking violations data to explore the dataset and extract meaningful insights.

Objectives
Clean and prepare the parking violations dataset for analysis.
Use Python libraries to manipulate and explore the data.
Investigate patterns and trends in parking violations.
Summarize findings using data-driven analysis.
Tools & Technologies
Python
Pandas
NumPy
Jupyter Notebook
Methodology
The project uses a Python-based analytical workflow to examine the dataset, prepare data for analysis, and investigate relevant patterns. Specific cleaning procedures and analytical methods will be documented based on the notebook implementation.
