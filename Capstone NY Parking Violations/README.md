# NYC Parking Violations Analysis - FY2024

## Project Overview
This capstone project was completed as part of the Data Science program at LaGuardia Community College. Using Python, I analyzed New York City parking violation data for Fiscal Year 2024 to explore ticket distribution across boroughs, vehicle types, registration states, violation codes, and locations.

The project involved working with a large public dataset, identifying missing values and inconsistencies, performing data cleaning, and using data analysis and visualization techniques to investigate parking enforcement patterns across New York City.

## Project Objectives
* Identify which NYC borough recorded the highest number of parking violations.
* Determine which vehicle registration states accounted for the most tickets.
* Examine the most frequently ticketed vehicle types and violation codes.
* Explore changes in violation counts over time.
* Investigate locations with high concentrations of parking violations.
  
## Tools & Technologies
* **Python** - data analysis and manipulation
* **Pandas** - data cleaning, grouping, and aggregation
* **NumPy** - numerical operations
* **Matplotlib** - data visualization
* **Seaborn** - statistical visualization
* **Jupyter Notebook** - interactive analysis and documentation
  
## Dataset
The analysis used the NYC Department of Finance's public parking violations dataset for Fiscal Year 2024.

* Initial dataset size: approximately **7 million records and 43 columns**.
* Data included issue dates, registration states, vehicle types, violation codes, boroughs, and street information.
* The dataset was used to examine geographic and categorical patterns in parking enforcement.

## Methodology
* Data Inspection: Examined the dataset's structure, column names, dimensions, and missing values.
* Data Cleaning: Investigated incomplete fields and inconsistencies in borough and location data.
* Data Manipulation: Used Pandas operations, including grouping, sorting, filtering, and aggregation, to summarize violations.
* Exploratory Data Analysis: Compared ticket counts by borough, registration state, vehicle type, violation code, and location.
* Data Visualization: Created charts using Matplotlib and Seaborn to communicate patterns and differences in the data.
  
## Key Findings
The analysis identified several notable patterns in the available FY2024 data:

* Borough distribution: Queens recorded the highest share of parking violations among the five boroughs, accounting for approximately 29.7% of the violations analyzed.
* Vehicle registration: New York-registered vehicles accounted for approximately 80.8% of tickets, followed by New Jersey at 10.5%.
* Vehicle types: Passenger vehicles represented approximately 87.2% of tickets, followed by commercial vehicles at 9.2% and taxis at 3.6%.
* Violation codes: Violation Code 36, identified in the notebook as a photo school-zone speed violation, was the most frequently issued violation in four boroughs: Queens, Brooklyn, the Bronx, and Staten Island.
* Trends over time:The analysis showed an increase in recorded violations from May through November 2023. December data was not fully updated at the time of the original analysis.
  
The dataset represents the records available when the project was conducted. These findings describe the analyzed records and should not be interpreted as proof of why violations occurred.
