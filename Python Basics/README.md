# Python Basics
## Project Overview

This project was completed as part of the Data Science program at LaGuardia Community College. It involved practicing Python programming fundamentals and learning how to write and execute code using Jupyter Notebook. Through this project, I developed my understanding of Python syntax, programming concepts, and problem-solving while building a foundation for future data analysis projects.
